# Объединитель прайс-листов поставщиков

Консольная программа на Python, которая загружает прайс-листы поставщиков в форматах CSV и XLSX, приводит названия колонок к общей структуре, очищает и проверяет данные, объединяет товары и сохраняет результат в Excel.

При повторяющемся артикуле программа оставляет предложение с минимальной ценой.

## Возможности

- чтение прайс-листов CSV и XLSX;
- сопоставление названий колонок через JSON-конфигурацию;
- очистка и проверка строк;
- объединение прайс-листов;
- обработка повторяющихся артикулов по минимальной цене;
- запуск из командной строки;
- автоматические тесты.

## Требования

- Python 3.12 или новее.

## Установка

Откройте PowerShell в папке проекта и выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
```

## Настройка колонок

Сопоставление колонок хранится в `config/mapping.json`. Ключ поставщика должен совпадать с именем файла без расширения. Например, для `supplier_a.csv` используется ключ `supplier_a`.

В конфигурации укажите, как называются в файле поставщика колонки артикула, названия, цены и остатка.

## Запуск

Из папки проекта выполните:

```powershell
price-merger --files examples/supplier_a.csv examples/supplier_b.xlsx --config config/mapping.json --output output/merged_price_list.xlsx
```

Параметры:

- `--files` — один или несколько входных CSV/XLSX-файлов;
- `--config` — путь к JSON-конфигурации колонок;
- `--output` — путь и имя итогового файла.

Имя поставщика программа определяет по имени входного файла.

## Запуск тестов

```powershell
python -m pytest
```
